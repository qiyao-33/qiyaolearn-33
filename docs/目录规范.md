# 目录规范

## 顶层结构

每门课程一个一级目录，命名使用中文课程名，例如 `高等数学`、`数据结构`。

## 课程内结构

每门课程下固定包含两个子目录：

```
课程名/
├── 历年试卷/   # 历年期末考试真题（PDF）
└── 复习笔记/   # 章节总结、复习要点（Markdown）
```

## 文件命名

| 类型 | 命名示例 |
|------|----------|
| 试卷 | `高等数学2024-2025-1期末卷.pdf` |
| 笔记 | `数据结构第3章-树与二叉树.md` |
| 总结 | `数据库原理期末复习大纲.md` |

## 禁止事项

- 禁止上传含个人隐私（姓名、学号、身份证号等）的文件；
- 禁止上传受版权保护且明确不允许传播的内容；
- 禁止上传可执行文件、压缩包（防止恶意代码）。
