# 📚 本校期末复习资料汇总库

> 一个开放、共享的期末复习资料库，收集各科历年试卷、复习笔记与章节总结，帮助同学们高效备考。

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](./LICENSE)

## 项目简介

「本校期末复习资料汇总库」是一个面向本校同学的期末复习资料共享项目。项目通过 GitHub 托管，按课程分类整理历年期末考试试卷、复习笔记、章节总结等资料，方便同学们集中查找、下载和贡献。

- 🗂 **按课程分类**：每门课程一个目录，试卷与笔记分开存放；
- 🤝 **开放贡献**：任何人都可以通过 Issue / Pull Request 提交或修正资料；
- 📄 **许可证明确**：采用 MIT 许可证，鼓励传播与二次整理；
- 🔍 **便于检索**：统一命名规范与目录结构，快速定位所需资料。

## 快速开始

### 浏览资料
直接点击上方目录，进入对应课程文件夹，即可查看历年试卷与复习笔记。

### 克隆仓库
```bash
git clone https://github.com/qiyao-33/qiyaolearn-33.git
cd qiyaolearn-33
```

## 如何贡献

我们非常欢迎你的贡献！无论是提交一份试卷、修正一处错误，还是补充一份笔记，都能帮助到更多同学。

1. Fork 本仓库；
2. 创建你的功能分支：`git checkout -b feature/你的修改`；
3. 提交你的更改：`git commit -m '添加XXX复习资料'`；
4. 推送到远程：`git push origin feature/你的修改`；
5. 发起 Pull Request。

详细的贡献流程与命名规范请见 [CONTRIBUTING.md](./CONTRIBUTING.md)。
