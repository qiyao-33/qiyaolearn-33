# 数据结构 第3章 树与二叉树

> 整理：吴禹龙　更新时间：2026-11

## 1. 基本概念

- 结点、度、深度、叶子结点
- 二叉树的性质：第 $i$ 层最多 $2^{i-1}$ 个结点；深度为 $k$ 的二叉树最多 $2^k-1$ 个结点

## 2. 二叉树的遍历

| 遍历 | 顺序 |
|------|------|
| 先序 | 根 → 左 → 右 |
| 中序 | 左 → 根 → 右 |
| 后序 | 左 → 右 → 根 |
| 层次 | 自上而下、自左而右 |

## 3. 遍历性质

- 已知「先序 + 中序」或「后序 + 中序」可唯一确定一棵二叉树；
- 已知「先序 + 后序」不能唯一确定。

## 4. 特殊二叉树

- 满二叉树、完全二叉树
- 二叉排序树（BST）：中序遍历得到递增序列
- 哈夫曼树与哈夫曼编码

## 5. 常考题型

1. 根据遍历序列还原二叉树
2. 计算结点数、深度、叶子数
3. 哈夫曼编码构造
